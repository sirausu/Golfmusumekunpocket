# プロテストへの道（ゴルフ育成シミュレーション）ver1.01

クラブを握ったこともない素人が、ゴルフ場の研修生になって、3年以内にプロテスト合格を目指す育成ゲームです。
パワプロクンポケット（パワポケ）やウマ娘の育成モードを参考にしています。

ブラウザだけで動きます。`index.html` を開けばそのまま遊べます。

## 遊び方

- 1週間は「平日」と「週末」の2回。練習・バイト・休む・おでかけから行動を選ぶ
- 3か月ごとの **査定ラウンド** で目標スコアを切れないとクビ（ゲームオーバー）
- 毎年、プロテスト（1次予選 → 2次予選 → 最終）に挑戦できる
- 難易度は家庭環境で決まる（裕福な家庭／普通の家庭／仕送りなし）。お金のやりくりが一番の壁
- 練習メニューは「絞る版（6種類）」と「絞らない版（8種類）」から選べる

## 主な仕組み

- **能力**：飛距離・正確性・アプローチ・パター・リカバリー・メンタル
- **コーチ・教本・道具・トレーニング用品**：お金をかけると伸びが良くなる
- **調子・体力・ケガ**：体力が少ないまま練習するとケガをしやすい
- **仲間との絆**：鬼塚・千夏・源さん・早乙女。絆30／65／100で特技が（小）→（中）→（大）。親友（絆100）は2人まで。しばらく会わないと絆が下がる
- **特技**：3択から1つ選ぶ。温泉以外で覚えるときはデメリット特性がセットで付く
- **金特**：特定の特技2つがそろうと上位の特技に進化
- **弱点**：約12週続く一時的な不調（チャンス×、スランプなど）
- **試合の天気**：晴れ・くもり・雨・強風。リカバリーが高いと悪天候に強い
- **ランダムイベント**：同じ選択でも結果が変わる。ダイジョバナイ博士も出る
- **早乙女とのマッチプレー**：毎年8月
- **ティーショットのミニゲーム**：打ちっぱなしで遊べる
- **周回要素**：合格すると引き継ぎポイント。次のゲームを有利にする特典や「早乙女markⅡ」を買える
- **殿堂入り**：合格した選手を残せる。殿堂入り同士で対抗戦もできる
- **殿堂入りツアー**：殿堂入りした選手でプロのツアー（年8試合）に出られる。最高の賞金記録が残る
- **プロテストの常連たち**：ミスターYなど名前付きの選手が毎年プロテストに出てくる
- **鳥よけのミニゲーム**：飛んでいく球を操作して鳥や木をよける。カラスの襲撃や、試合中のまれな出来事で遊ぶ
- **コース攻略のミニゲーム**：上から見た地図で狙う場所を決めて、動く針を止めて打つ。プロテストでは本番前に1回プレイし、その結果が同じパーの2ホールのスコアになる。120ヤード以内で地図を拡大するかどうかは、地図の右下のボタンで切り替えられる
- **はじめての人向け**：まだ合格したことがないと、練習道具6つを最初から持って始まる

## ファイル構成

```
index.html      遊ぶためのファイル（src/ をつなげて作ったもの）
build.sh        src/ から index.html を作るスクリプト
src/
  head.html     画面の見た目（CSS）
  engine.js     試合の計算（1打ごとの結果、天気など）
  game.js       育成の計算（練習・お金・日程・特技・絆など）
  events.js     ランダムイベント
  scenes.js     ドット絵の場面
  ui.js         画面の表示と操作
tools/
  sim.js        自動プレイで難易度を確かめる道具（Node.js で動く）
```

## 作り方

```sh
sh build.sh          # src/ を変えたら、これで index.html を作り直す
node tools/sim.js    # 自動プレイで、難易度ごとの合格率を確かめる
```

## 保存について

記録はブラウザの保存領域（localStorage）に残ります。
Claude の画面で開いたときだけ、クラウドにも保存されます。GitHub Pages などで開いた場合は、その端末のブラウザだけに残ります。
